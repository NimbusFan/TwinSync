# TwinSync v1.0.0-beta.1

TwinSync 的首次公开测试版本，面向 Windows 10/11，要求 .NET Framework 4.7.2 或更高版本。

## 主要功能

- 原生 C# 同步核心与本地网页管理，关闭网页后继续后台运行。
- 局域网自动发现、用户确认配对、TLS 1.2 加密和固定设备指纹核验。
- 双向、仅发送、仅接收，以及按文件夹或设备控制共享范围。
- 目录浏览、空间分布、搜索、文件下载与资源管理器定位。
- 历史版本、分段文本差异、逐项批量恢复结果与失败项重试。
- 按文件夹与变化路径合并扫描，保留定期完整核对。
- 分块校验、断点续传和临时网络故障的延迟重试。
- 有容量上限的运行记录和脱敏诊断导出。
- 文件字节进度、传输速度和失败项目查看。
- 可选择安装目录、Windows 托盘和登录后台启动。

## 下载

- `TwinSyncSetup.exe`：Windows 安装程序。
- `TwinSync-source.zip`：源码、前端资源、测试、构建脚本及依赖。

两台电脑分别安装、设置名称并配对。首次运行需要自己选择同步文件夹。

## 已知限制

- 局域网自动发现依赖 UDP 55221，网络隔离或防火墙拦截时需手动填写地址。
- 两端更新后可使用断点续传；旧端保留完整传输兼容。
- 文本差异按段计算，不能作为跨段移动或全文变更的统计结果。
- 当前为公开测试版本，尚未完成广泛的长期真机验证或独立安全审计。重要数据应保留独立备份。

## 升级注意

升级前先从托盘退出旧服务。卸载会保留配置、历史版本和同步文件；不要将一台电脑的整个身份数据目录复制给另一台电脑。
